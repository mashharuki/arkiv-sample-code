# arkiv-sample-code

This repo for arkiv sample code

## install Agent SKILL

```bash
pnpm dlx skills add Arkiv-Network/skills --skill arkiv
```

## Quick Start

```bash
cd arkiv-hello
bun install

bun run dev
```
